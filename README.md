# 🧬 Helix Scan

Helix Scan is a web-based DNA analysis tool that lets users input genome sequences and explore them through a clean, interactive interface.

It runs in the browser with no hardware or installation needed, and presents results visually so patterns are easy to spot.


## live demo

 https://akshithahh-03.github.io/helix-scan/

## ✨ Features

- Input and analyze DNA / genome sequences
- Interactive, easy-to-read visual results
- Fast, lightweight, and fully web-based
- Responsive design that works on desktop and mobile

## 🛠️ Tech Stack

- HTML, CSS, JavaScript
- Deployed on Netlify

## 🚀 Run Locally

1. Clone or download this repository
2. Open the project folder in VS Code
3. Open `index.html` in your browser (or run `npm install` and `npm run dev` if the project has a `package.json`)
